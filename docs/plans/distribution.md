## Objective

Package and distribute the existing generated artifacts (`tokens/` and `terminals/`) so downstream consumers can install them via standard package managers and CDNs instead of cloning the repo.

## Current State

All artifacts are already generated by `pnpm run build` / `pnpm run tokens`:

- `tokens/zerotosaas.css` — CSS custom properties for all 20 variants
- `tokens/tailwind.preset.js` — Tailwind CSS v3 preset
- `tokens/tailwind.v4.css` — Tailwind CSS v4 `@theme` block
- `tokens/zerotosaas.json` — Style Dictionary / Figma Tokens Studio format
- `terminals/<terminal>/<slug>.<ext>` — 140 files across 7 terminals × 20 themes

Usage instructions for all formats are already documented in `docs/guides/Cross-Platform.md`.

## Plan

### 1. npm package: `@zerotosaas/tokens`

A single npm package containing all 4 token formats.

```
@zerotosaas/tokens/
├── package.json
├── zerotosaas.css          # CSS custom properties
├── tailwind.preset.js      # Tailwind v3 preset
├── tailwind.v4.css         # Tailwind v4 @theme
└── zerotosaas.json         # Style Dictionary / Figma
```

- Publish to npm with each release
- Available via jsDelivr CDN: `https://cdn.jsdelivr.net/npm/@zerotosaas/tokens/zerotosaas.css`
- Consumers import what they need (CSS, JS, or JSON)

### 2. Terminal bundles

A single downloadable archive per terminal containing all 20 schemes, plus a universal install script.

- `terminals/zerotosaas-iterm2.zip` — 20 `.itermcolors` files
- `terminals/zerotosaas-macos-terminal.zip` — 20 `.terminal` files
- `terminals/zerotosaas-windows-terminal.json` — combined JSON with all 20 schemes
- `terminals/zerotosaas-alacritty.zip` — 20 `.toml` files
- `terminals/zerotosaas-kitty.zip` — 20 `.conf` files
- `terminals/zerotosaas-ghostty.zip` — 20 `.conf` files
- `terminals/zerotosaas-warp.zip` — 20 `.yaml` files

Attach all bundles to each GitHub Release as assets.

### 3. Install script

A single `install-terminals.sh` that detects the OS and available terminals, then copies the appropriate schemes to the right config directories:

```bash
curl -fsSL https://zerotosaas.in/install-terminals.sh | bash
```
