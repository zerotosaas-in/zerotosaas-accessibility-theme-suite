## Current State

20 Alacritty color scheme files exist at `terminals/alacritty/<slug>.toml`, generated by `scripts/export-tokens.js`. Each TOML file contains `[colors.primary]`, `[colors.cursor]`, `[colors.selection]`, `[colors.normal]`, and `[colors.bright]` blocks. Users import via `import = ["/path/to/slug.toml"]` in their `alacritty.toml`.

## Distribution Goals

1. **Crates.io theme crate** — `cargo install alacritty-themes-zerotosaas` (or a CLI tool that lists and applies themes)
2. **Combined TOML bundle** — a single downloadable archive with all 20 `.toml` files
3. **Install script** — `curl -fsSL https://zerotosaas.in/alacritty/install.sh | bash` that copies schemes to `~/.config/alacritty/themes/`
4. **Documentation** — installation guide
