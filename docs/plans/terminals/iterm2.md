## Current State

20 iTerm2 color scheme files exist at `terminals/iterm2/<slug>.itermcolors`, generated by `scripts/export-tokens.js`. Each file maps the theme's ANSI 0–15 colors, background, foreground, cursor, and selection. Users currently import manually via double-click or iTerm2 → Settings → Profiles → Colors → Color Presets.

## Distribution Goals

1. **iTerm2 Color Presets repository** — publish all 20 schemes as a single importable bundle
2. **Homebrew tap** — `brew install --cask zerotosaas-iterm2-colors` to install all presets system-wide
3. **One-click install script** — `curl -fsSL https://zerotosaas.in/iterm2/install.sh | bash` that imports all 20 schemes into iTerm2's Color Presets directory
4. **Documentation** — installation guide with screenshots in `docs/guides/Cross-Platform.md`
