## Current State

20 Windows Terminal scheme files exist at `terminals/windows-terminal/<slug>.json`, generated by `scripts/export-tokens.js`. Each JSON file contains the `name`, `background`, `foreground`, `cursorColor`, `selectionBackground`, and `black` through `white` ANSI color keys. Users manually paste the JSON into Windows Terminal's `settings.json` schemes array.

## Distribution Goals

1. **PowerShell install script** — `irm https://zerotosaas.in/wt/install.ps1 | iex` that injects all 20 schemes into Windows Terminal `settings.json`
2. **Winget package** — `winget install zerotosaas.windows-terminal-themes`
3. **Combined JSON bundle** — a single `zerotosaas-wt-schemes.json` containing all 20 schemes for manual import
4. **Documentation** — installation guide with screenshots
