## Current State

20 Warp color scheme files exist at `terminals/warp/<slug>.yaml`, generated by `scripts/export-tokens.js`. Each YAML file contains Warp's theme spec with `background`, `foreground`, `details` (e.g. `darker`/`lighter`), `terminal_colors` (normal + bright ANSI 0–15), and metadata. Users install by copying to `~/.warp/themes/` and selecting in Settings → Appearance → Themes.

## Distribution Goals

1. **Warp themes bundle** — a single downloadable archive with all 20 `.yaml` files
2. **Install script** — `curl -fsSL https://zerotosaas.in/warp/install.sh | bash` that copies schemes to `~/.warp/themes/`
3. **Warp themes PR** — submit themes to the official `warpdot/themes` repository for inclusion
4. **Documentation** — installation guide
