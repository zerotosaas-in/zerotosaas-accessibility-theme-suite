## Current State

20 Ghostty color scheme files exist at `terminals/ghostty/<slug>.conf`, generated by `scripts/export-tokens.js`. Each `.conf` file contains `palette = 0=#hex` through `palette = 15=#hex`, `background`, `foreground`, `cursor-color`, and `selection-background` keys. Users install by copying to `~/.config/ghostty/themes/` and referencing via `theme = <name>` in their Ghostty config.

## Distribution Goals

1. **Ghostty themes bundle** — a single downloadable archive with all 20 `.conf` files
2. **Install script** — `curl -fsSL https://zerotosaas.in/ghostty/install.sh | bash` that copies schemes to `~/.config/ghostty/themes/`
3. **Ghostty built-in themes PR** — submit themes to the Ghostty project for inclusion as built-in themes
4. **Documentation** — installation guide
