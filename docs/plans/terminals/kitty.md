## Current State

20 Kitty color scheme files exist at `terminals/kitty/<slug>.conf`, generated by `scripts/export-tokens.js`. Each `.conf` file contains `color0` through `color15`, `background`, `foreground`, `cursor`, and `selection_background`/`selection_foreground` keys. Users install by copying to `~/.config/kitty/themes/` and including in `kitty.conf`.

## Distribution Goals

1. **Kitty themes directory bundle** — a single downloadable archive with all 20 `.conf` files
2. **Install script** — `curl -fsSL https://zerotosaas.in/kitty/install.sh | bash` that copies schemes to `~/.config/kitty/themes/`
3. **kitty-themes PR** — submit themes to the official `kitty-themes` repository for inclusion
4. **Documentation** — installation guide
