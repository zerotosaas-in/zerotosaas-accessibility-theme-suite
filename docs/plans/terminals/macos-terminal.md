## Current State

20 Terminal.app profile files exist at `terminals/macos-terminal/<slug>.terminal`, generated by `scripts/export-tokens.js`. Files contain binary NSKeyedArchiver color blobs (NSColorSpace=2, null-terminated NSRGB) validated with `plutil -lint`. Users import via double-click or Terminal → Settings → Profiles → Import.

## Distribution Goals

1. **One-click install script** — `curl -fsSL https://zerotosaas.in/terminal-app/install.sh | bash` that imports all 20 profiles
2. **Homebrew tap** — `brew install --cask zerotosaas-terminal-profiles`
3. **Documentation** — installation guide with screenshots
